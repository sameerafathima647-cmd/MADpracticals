# Mobile Application Development Practicals

Code from the uploaded **Mobile Application programs.pdf** has been separated into individual practical folders for GitHub.

## Folder guide

Each `Practical-XX-...` folder contains:
- `XML/` — Android layout/menu/resource XML files
- `Java/` — Java source files
- `AndroidManifest.xml` at the practical folder root, when it was present in the PDF
- `README.md` — the original practical heading and file list

## Important
- These are **source-code files**, not complete Android Studio projects.
- The code is separated from the PDF; it has not been guaranteed to compile without changes.
- The PDF section for **Personal Details GUI** and **Layout Managers** contains XML only, so no Java file was supplied for those two sections.
- Some programs need extra setup, such as permissions, drawable images, animation resources, or AndroidManifest entries. Check each practical in Android Studio.
- Upload the ZIP's extracted folders to your GitHub repository. Do not upload the ZIP itself if you want each code file visible line by line on GitHub.
